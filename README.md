# library-service

Сервіс видачі книг. Писав практикант минулого року, документацію не залишив.

## Штрафи читача

`GET /api/readers/:id/fines` повертає суму штрафів і кількість повернених книг зі штрафом:

```json
{ "readerId": 1, "total": 40, "loans": 2 }
```

Маршрут доступний бібліотекарю для будь-якого читача та читачу лише для власного профілю.

```
npm install
npm test
npm start
```
